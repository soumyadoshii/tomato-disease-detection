🍅 Tomato Leaf Disease Detection with Deep Learning & Explainable AI (XAI)An end-to-end deep learning framework designed to detect, classify, and explain tomato leaf diseases across 11 classes (10 disease classes + 1 healthy class).This project benchmarks five deep learning architectures (ResNet50, EfficientNet-B0, DenseNet-121, ConvNeXt-Tiny, and Vision Transformer / ViT-B/16) using comprehensive performance metrics. To overcome the "black-box" nature of neural networks, integrated Grad-CAM and LIME explanations provide transparent visual interpretations of model decisions.📌 Project OverviewComparative Architecture Benchmarking: Evaluates CNNs and Vision Transformers on classification accuracy and generalization.Explainable AI (XAI) Integration: Uses Grad-CAM heatmaps to map feature attention layers and LIME superpixel segmentation to identify influential pixels.Interactive Inference Interface: Includes a Streamlit web application for real-time leaf image diagnosis and XAI rendering.Standardized Pipeline: modular codebase separating dataset preprocessing, model creation, evaluation, explainability, and web interface logic.📊 Dataset SummaryThe training and evaluation pipeline utilizes tomato ⚡ Quickstart Guide1. Clone the RepositoryBashgit clone https://github.com/soumyadoshii/tomato-disease-detection.git
cd tomato-disease-detection
2. Install DependenciesBashpip install -r requirements.txt
3. Verify Dataset LoaderEnsure your dataset is placed under the data/ folder structured into train, valid, and test directories, then verify:Bashpython src/dataset.py
4. Train & Evaluate ModelsTo train a model architecture (e.g., ResNet50) and save weight checkpoints:Bashpython src/train_eval.py
5. Launch Web InterfaceRun the Streamlit application to upload leaf images, view disease predictions, and inspect Grad-CAM/LIME visual maps:Bashpython -m streamlit run app.py
